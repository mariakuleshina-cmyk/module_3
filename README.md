# module3

Приложение для обучения нейросети. Модуль 3.

## Запуск
Двойной клик по `module3.bat` (нужен установленный Python с зависимостями из `requirements.txt`).

## Рядом с EXE должны лежать
- `data.db` — база с обучающими данными
- `training_log.db` — логи обучения (создаётся сам)
- `traffic_model.keras` — модель (создаётся после первой эпохи)
